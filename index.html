Technical details, privacy & static guard scope

Zero dependencies: Runs on Python 3.11+ standard library with vendored MIT pylatexenc 2.11. Optional local bibtex, --fls (TeX -recorder), --aux, and pandoc oracles activate automatically when installed.

Data handling: Local apps bind strictly to 127.0.0.1 with per-session CSRF tokens and CSP nonces. Online BibTeX verification is opt-in and sends only citation metadata (DOI, title, author) to public Crossref, DataCite, OpenAlex, DBLP, and arXiv endpoints—never manuscript prose.

Static guard boundaries: latex_guard.py confirms checked formulas, labels, and citations are unchanged; full TeX compilation is verified separately by pdflatex/latexmk. Local brace-scoped macro/register redefinitions, \documentclass[opts] forwarding to custom packages, and unbraced register forms are outside static simulation scope.
